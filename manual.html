1. 初期設定

Gemini API Key（必須） — Google AI Studioで無料取得

Azure Speech Key（推奨） — Azure Portal → Speech Services

💡 Azure Keyがなくてもテキスト入力とブラウザ音声で使えます。ただし Shadowing の発音評価と発音ドリルの採点には必須です。

2. 🚀 自動ルーティン

レベルとテーマを選ぶだけで4モードを自動連続。約15分。

  1. 🗣️ Free Talk — 3ターン（最後はAIが自然に締める）
  2. ⚡ Flash — 5問
  3. 🎨 Description — 5シナリオ
  4. 🎧 Shadowing — 5文
  5. 🎉 完了 — 4セクション総合スコア

レベルは開始画面で選択し、4セクションすべてに適用されます。テーマも全セクションで統一されるので、Free Talkで話した話題がそのままFlash・Description・Shadowingに引き継がれます。

12テーマ: 日常 / ビジネス / 旅行 / 意見・社会 / 食べ物 / 経済・金融 / テクノロジー / 健康 / 文化 / 趣味 / 家族 / 自分のこと

3. 🗣️ Free Talk

17カテゴリ・221トピック（うち🎭ロールプレイ68種）。全カテゴリでフリーワード入力も可能。

ターン数

3 / 5 / 7 / 10 / ∞ から選択。表示は「あなた2/5」のように自分の発言回数を数えます（AIの発言は含みません）。∞ の場合は「🏁 終了してフィードバック」で手動終了。

🙋 自分からスタート

ONにすると自分が最初に話します。会議の進行、プレゼン、道案内など自分から切り出す場面の練習に。

AIの会話スタイル

毎回質問で返すのではなく、共感・自分の話・リアクション・エピソードを自然に混ぜます。尋問ではなく会話になるよう設計しています。

チャレンジ表現

22スキルカテゴリから、その話題で使いやすい短いフレーズ（2〜6語）を提示。使えなかった表現は自動で復習キューに入ります。

4. ⚡ Flash Training

カテゴリ内容
🏠 日常 / 💼 ビジネス / ✈️ 旅行 / 💭 意見日本語→英語の翻訳
⚡ 状況反応状況説明を読んで英語で即応答（翻訳ではない）
🔄 パターンドリル同じ型を複数状況で反復し自動化する

30シード×10文体で40,600通り以上。直近50問は再出題されません。

💡 大文字・句読点は評価対象外です（音声入力で制御できないため）。スキップした問題は平均点から除外されます。

5. 🎨 Description

具体的なシナリオを与えられ、自分の言葉で説明する独立モード。5問が段階的に難しくなります。

  1. 🟢 報告 — ひとこと〜2文で事実を伝える
  2. 🟢 叙述 — 2〜3文で出来事を順に話す
  3. 🟡 説明 — 原因や理由を述べる
  4. 🔴 比較・説得 — 選択肢を比較して意見を言う
  5. 🔴 即興対応 — 予想外の展開にその場で対応する

例:「今朝、駅でコーヒーをこぼして隣の外国人のコートを汚してしまった。英語でなんて謝る？」

評価は内容の適切さ・語彙の幅・文法。模範解答に加えて✨改善案が出ます。テーマ×場面×展開で3,000通り以上。

⚠️ このモードだけ、シナリオの質を優先して常に Gemini 3.7 Flash を使用します。コストは他モードと分けて計上されます。

6. 🎧 Shadowing

AIの英語を聞いて繰り返し、Azureで発音を採点。5文1セット。

  • 🙈 テキスト非表示モード（耳だけで再現）
  • 単語ごとの色分け（🟢正確 🟡要改善 🔴不正確、取消線＝未発話）
  • 🔊 お手本を聞く / 🎙️ 自分の録音を聞く
  • 🔄 最低スコアの文だけリトライ
  • ✨ AI発音アドバイス（有料オプション）

スコアはレベルとテキスト非表示で補正されます。難しい条件で練習した方が正当に評価されます。

補正係数
A1 / A2 / B1 / B2 / C1×0.85 / ×0.92 / ×1.00 / ×1.08 / ×1.15
テキスト非表示×1.10

70点未満だった単語は自動的に 発音練習 のリストに追加されます（未発話の語は除外）。

7. 👂 Listening Quiz

聞いてタップするだけ。マイク不要・発声不要なので電車でも練習できます。10問で約5分。

タイプ測るもの
🔤 穴埋め弱く発音される語を拾えるか
🎭 意図・感情トーンから話者の気持ちを読めるか
🔗 弱形・短縮can/can't、gonna/gotta など紛らわしい音の判別
💬 次の一言内容を踏まえて自然な返答を選べるか
🔢 数字・固有名詞B12とB20、13と30などを聞き分けられるか
🎲 ミックス上記を2問ずつ

選択肢は音声を聞かないと答えられないよう設計されています（3択すべて自然で、文法や丁寧さから正解が分からないようにする）。音声は何度でも再生でき、回答後にスクリプトと解説が出ます。

8. 🔁 4/3/2 Fluency

同じ話を50秒 → 40秒 → 30秒で3回話すフルエンシー訓練です。内容は変えず、制限時間だけを短くすることで「詰まらずに話す力」を鍛えます。

お題の決まり方

起動すると、その日の Free Talk の話題を自動で拾って先頭に出します。朝に話した内容を夜にもう一度話す使い方を想定しています。朝にやっていない日はテーマを選べます。

🎯 お題
🌅 今日の朝の話題「会議」— 同じ話題をもう一度、短く話す
［🏠日常］［💼ビジネス］［✈️旅行］…

流れ

  1. 準備 30秒（スキップ可）— 話す内容を考える
  2. Round 1 — 50秒
  3. Round 2 — 40秒（前回の数値を見ながら、同じ話をもっと短く）
  4. Round 3 — 30秒
  5. 3回分をまとめて比較

カウントダウンが表示され、残り5秒で赤くなります。時間切れで自動停止します。

評価

各ラウンド終了時に WPM・語数・フィラー率 がその場で出ます（um / uh / like / you know などをローカル判定するので無料）。

3回終わると、3回分の文字起こしをまとめて1回のAPI呼び出しで比較します。

軸見るもの
内容圧縮しても要点が生き残ったか
構成話の組み立てが整理されたか
表現語彙が的確・自然になったか
流暢さ言い淀み・言い直しが減ったか
💡 速く話すだけでは高評価になりません。要点を落として短くした場合は「内容」スコアが下がります。「✅良くなった点／⚠️落ちた点／💡次回のアドバイス」も出ます。
⚠️ 文字起こしに Azure Speech キーが必要です。未設定だと内容の比較ができません。

9. 📰 News Discussion

22ジャンル＋フリーワード。ターン数は3/5/7から選択。Google Search Grounding で実際の最新ニュースを取得します。

記事の長さと難しさはレベルで変わります（A1: 30〜50語 / B1: 80〜100語 / C1: 120〜180語）。同じニュースをレベルに合わせて書き換える方式です。ルーティンには含まれません。

11. 🎯 発音練習

Shadowingで70点未満だった単語が自動で貯まります。ドリルでは録音して採点できます。

through　[🔊 単語を聞く]
💡「スルー」ではなく θruː。舌先を上の前歯に軽く当てて息を出す。

📝 この文で練習
I walked through the park.
[🔊 お手本] [🎤 録音して採点]

→ 62点「through」の発音スコア　❌ もう一度

例文の中でその単語が何点だったかを見るので、単語単独より安定して評価できます。

条件結果
70点以上✅ 合格
80点以上を2回リストから卒業（自動削除）

出題方式

  • 🎯 おまかせ（既定）— 苦手4語・伸び途中3語・卒業間近3語をバランスよく。直近12時間に練習した語は後回し
  • 📉 苦手順 — スコアが低い順に10語
  • 🎲 ランダム — 全体から10語

12. 📚 フレーズ集・💬 会話ログ

📚 フレーズ集

会話で使ったフレーズを自動抽出。🔊で発音再生、✕で個別削除、✨で例文と🏷️使用シーンを生成します。

💡 知っているフレーズは✕で消して、使いたいものだけ残すと使いやすくなります。

💬 会話ログ

最大50件。🇯🇵和訳を表示すると保存されるので2回目以降は無料で即表示されます。Description の履歴は自分の発言だけを翻訳します（AI側は元から日本語を含むため）。

13. 📊 分析

HOME の「📊 分析」から。履歴（セッション一覧）とは別画面です。

  • スキルバランス — モード別レーダー。直近2週間と1ヶ月を重ねて成長を見る
  • 🎯 弱点分析 — 6軸（発音 / 流暢さ / 文法 / 語彙 / 自然さ / 瞬発力）＋自動アドバイス
  • 🏷️ 間違いの傾向 — 時制・冠詞・前置詞・語順・語彙選択など10分類。過去分はボタンでまとめて分類可能（有料）
  • 👂 リスニング分析 — タイプ別の正答率。直近50問で判定（10問未満は参考値）
  • 📈 スコア推移 — 日別・1ヶ月・モード色分け
  • 📅 週別学習推移 — セッション数と学習時間の8週間推移
  • 🎓 CEFRレベル推移 — A1〜C1を13段階（A2+、B1+など中間も表示）

瞬発力は Free Talk と Flash から算出します（応答速度40%＋発話密度60%）。フィラーが多くダラダラした回答は低く出ます。

14. CEFRレベル

レベル語彙文法
A1〜500現在形・can のみ
A2〜1,500過去形・going to・比較級
B1〜3,000現在完了・第一条件文・受動態

各レベルに使用禁止文法リストがあり、AIはそれを厳守します。読み上げ速度は全レベル自然速度で、差は語彙・文法・振る舞いで付けています。

17. 学習のコツ

🚀 ルーティンを毎日 — テーマを変えながら朝晩15分。4モードが同じ話題で繋がります。

📝 復習は「思い出してから」開く — 答えを見る前に必ず声か頭の中で言ってみる。ここを飛ばすと効果が大きく落ちます。

🎯 発音は卒業まで回す — おまかせモードなら卒業間近の語が毎回混ざるので、リストが着実に減ります。

👂 移動中はListening Quiz — マイク不要なので電車でも。弱形・短縮が伸びると会話の聞き取りが一気に楽になります。

🔁 朝と夜をつなぐ — 朝のルーティンで話した話題を、夜に 4/3/2 でもう一度。同じ内容を短く話し直すのが一番効きます。

📊 週1で分析を見る — 「間違いの傾向」で冠詞や前置詞など具体的な弱点が分かったら、Flashのカテゴリを選んで集中的に潰す。
